Quick start

Pick a workflow on the left, or create one from a preset: Home-tasks (merge → generalist → fine-tunes), Master RGB-D / UMI (record once → extract subsets → two-stage pre-train), or Max-data 18/12-DOF (merge everything locally cached, compare policy architectures). Before adding an external dataset, preflight it in Compare datasets; write or import one in Recipes; the full recipe lives in the Guide tab and GUIDE.md.

Run and Run all execute stages directly on this machine — no copy-pasting. Every stage is also written to workflows/<name>/scripts/*.sh when you hit Generate scripts, so anything can be re-run by hand or on another box. Watch progress on the Log tab — it lights up while a stage is running, and the sidebar list dots whichever saved workflow is currently active.

What's a recipe?

        

        A recipe is just a workflow — the same {name, variables, stages} JSON this
        app already saves and runs. Write one by hand, or hand the schema reference below to an
        LLM along with a description of the pipeline you want ("merge these 3 datasets, pretrain
        SmolVLA for 60k steps, fine-tune on X and Y") and it can fill out the JSON directly.
        Download the template to get a valid starting point covering every stage type, then
        drop the filled-out result back in below to import it as a runnable workflow.
